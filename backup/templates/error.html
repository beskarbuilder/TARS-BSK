Soluciones Comunes
  • 🔌 Error de dispositivo:
    Verifica que el dispositivo esté conectado y montado correctamente
  • 💾 Error de espacio:
    Comprueba que hay suficiente espacio en el dispositivo de destino
  • 🗂️ Error de permisos:
    Asegúrate de tener permisos de escritura en la ruta seleccionada
  • 🔄 Si el backup falla:
    Cuando ni rsync ni la lógica pueden salvarte (exit code ≠ 0): sudo eject $(find /media -name TARS_BACKUP -print -quit) || echo "Respaldo abortado. Los datos eligieron no sobrevivir." > /dev/null
Información de Depuración
🔍 Verificaciones Rápidas
  • Estado del servicio TARS
  • Conectividad con Home Assistant
  • Permisos de archivos de configuración
  • Logs del sistema recientes
📋 Comandos Útiles
# Verificar estado
systemctl status tars

# Ver logs recientes  
journalctl -u tars -f

# Reiniciar servicio
sudo systemctl restart tars
Si el error persiste, revisa los logs del sistema para obtener más detalles sobre la causa raíz del problema.
