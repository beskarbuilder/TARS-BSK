Soluciones Comunes
  • 🔌 Error de conexión:
    Verifica que Home Assistant esté funcionando y accesible
  • 📄 Error de archivo:
    Asegúrate de que homeassistant_plugin.py existe y es accesible
  • ⚙️ Error de configuración:
    Revisa config/plugins.json para configuración de HA
  • 🔄 Si todo falla:
    Cuando la realidad colapsa (exit code ≠ 0): ./setup.void || echo "SOS ${USER}'s reality crashed" > /dev/iss/panic
