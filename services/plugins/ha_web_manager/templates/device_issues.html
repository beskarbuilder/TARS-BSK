Gestión de Dispositivos Problemáticos

Esta página identifica dispositivos que no responden correctamente a Home Assistant. Usa "Ocultar" para sacarlos de esta vista temporalmente.

Nota: "Ocultar" solo quita el dispositivo de esta pantalla. Recarga la página para verlo de nuevo.
Acciones Rápidas

Analizando dispositivos...

📝 1. Abrir archivo de configuración JSON
nano ~/tars_files/config/user_devices.json
🔍 2. Localizar dispositivo problemático

Busca en las categorías hasta encontrar el dispositivo:

{
          "dispositivos_configurados": {
            "luces": {
              "luz_problema": { ... },
              "luz_buena": { ... }
            },
            "interruptores_enchufes": {
              "switch_problema": { ... }
            },
            "sensores": {
              "sensor_problema": { ... }
            }
          }
        }
🗑️ 3. Eliminar entrada completa

Elimina TODO el bloque del dispositivo problemático:

# ANTES:
        "luces": {
          "luz_problema": {
            "entity_id": "light.rota",
            "type": "light",
            "location": "salón",
            "aliases": ["..."]
          },
          "luz_buena": { ... }
        }

        # DESPUÉS:
        "luces": {
          "luz_buena": { ... }
        }
💾 4. Guardar y aplicar cambios
Guardar: Ctrl+X → Y → Enter
Reiniciar: sudo systemctl restart tars
O recargar: Esta página se actualizará automáticamente
Ubicación de archivos importantes:
  • Configuración de dispositivos: ~/tars_files/config/user_devices.json
  • Issues/Problemáticos: ~/tars_files/services/plugins/ha_web_manager/issues_devices.json
  • Logs del sistema: ~/tars_files/services/plugins/ha_web_manager/logs/
  • Archivo Python (legacy): ~/tars_files/services/plugins/homeassistant_plugin.py

💡 Consejo: La configuración actual usa el archivo JSON. El archivo Python se mantiene para compatibilidad pero ya no se edita manualmente.

🎯 ¿Para qué sirve Issues?
  • Cuarentena inteligente: Dispositivos que fallan pero no quieres eliminar
  • Dashboard limpio: Solo ver dispositivos que funcionan
  • Gestión separada: Arreglar problemas sin interferir con el uso diario
  • Historial: Seguimiento de qué dispositivos dan problemas
✅ Flujo de trabajo recomendado
1. Detectar problema:
   • Dispositivo no responde en dashboard
   • Test falla repetidamente

2. Enviar a Issues:
   • Botón amarillo en dashboard
   • Dispositivo desaparece del dashboard

3. Gestionar en Issues:
   • "Re-test" para verificar si se arregló
   • "Marcar" para documentar problema conocido
   • "Restaurar" cuando funcione de nuevo

4. Limpieza final:
   • Si nunca se arregla → Eliminar definitivamente
🔧 ¿Qué hace cada botón?

Verifica si el dispositivo ya funciona. Si el test pasa, puedes restaurarlo al dashboard.

Registra en logs que es un problema conocido. El dispositivo sigue en Issues para seguimiento.

🔌 Enchufe inteligente desconectado
Issues → Re-test cuando se reconecte → Restaurar
💡 Bombilla que falló
Issues → Marcar → Eliminar cuando compres nueva
📱 Sensor con batería baja
Issues → Cambiar batería → Re-test → Restaurar
